css-twins

Edit the CSS below and the report next to it updates. It runs the real analyzer in your browser, so nothing is sent anywhere. Source on GitHub.

Try this

  1. Change 18px to 16px in .ctaButton. The two buttons go from 98% to 100% alike.
  2. Change 160ms to 150ms in .ctaButton. The stray timing goes away.
  3. Drag the slider to 95%. The cards are only 94% alike, so they drop out of the report.
  4. fade-in and appear are written differently but do the same thing, so they count as 100% alike.
  5. Paste in your own CSS. Start each file with a /* @file name.css */ line.

Files with :root tokens hold your shared classes, so copies elsewhere get pointed at them.
